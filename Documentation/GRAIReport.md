# GRAI Report
## Goal - What I want to archieve 

I want to LEVEL 5 — Enterprise Asset Management System in "weekly mini Projects - Assets Tracking-2.pdf" in the course materials in 1 week.

## Result - What actually happened

I archieve LEVEL 3 instead. 

## Analysis - Why it happened

The main reason is that my previous project "WeeklyProject03_AssetTracking" was not well structured.
I used clean architecture that generated by AI in the previous project. I thought AI generated code would be good enough before this project, but it turned out to be a mess.
Because clean architecture is complex and it was not well implemented, it made the code hard to understand and maintain.
When I tried to change hardcoded sample data to database, I found it hard to integrate Entity Framework Core with the existing code structure.
I need to refactor the code to make it more modular and easier to work with, which took a lot of time and effort.

## Insight - What I learned and what I will do next time

Free-tier Chatgpt is not good at generating complex code structures like clean architecture. 
It looks good on the surface and it could run, but it is a mess when you want to modify or extend the code.
AI is fast and can generate code quickly, but reviewing and refactoring the code is still necessary to ensure code quality and maintainability.

In next time, I use only AI to generate code snippets for specific functions or features, and then I will review and refactor the code to fit my needs and ensure it is well structured and maintainable.
Also, clean architecture is not the best choice for small projects. It is better to use a simple architecture that is easy for me to understand and maintain.
